# Rider

Rider is a front-end prototype for campus keke bookings at Veritas University, Abuja.

## Run locally

Open `index.html` in a browser. The booking screen is available from the **Book a Ride** button on the landing page.

## Prototype status

This version uses static demo content and does not connect to a backend or process real bookings or payments. The map and fare shown on the booking screen are illustrative.
